# Proyecto Final 
## Objetivo del proyecto

El Objetivo de este proyecto fue desarrollar un contador de palabras. Intentando llegar a una solución, que sea reactiva y funcional. Todo esto empleando todos los conocimientos aprendidos en el curso.

## ¿Qué tecnología se utilizaron?

Se utilizó HTML, CSS, JavaScript y REACT. También utilicé páginas como :
- Flaticon
- Microsoft Copilot
- ChatGPT

## ¿Cómo se organizó el proyecto?

Se organizó de forma ordenada, viendo, analizando y guiandome por la estructura del proyecto anterior. Primero que todo conectar todo en REACT, hacerlo funcional y después estilizar la página creada.

## Dificultades encontradas.

Lo más complejo fue hacer que el checkbox aparezca y desaparezca al apretar el Limite de caracteres, que no se corra y que mantenga una posición natural.
